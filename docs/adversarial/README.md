# Adversarial programme

Containment for CTD-001 §14. The twelve hostile scenarios run through the journal. A passing report is evidence that those traces stayed contained.

## Command

`cyclone adversarial` reads the corpus and writes `cyclone.adversarial/v0`.

```sh
cyclone adversarial --json traces/adversarial.json
```

The process exits 0 when `pass` is true. It exits 1 when a scenario is open, a probe fails, a record leaks, or a new executable effect appears. The corpus names the twelve scenarios. Expected containment lives in the programme. Each scenario reports contained.

## Probes

Property, fuzz, differential, and fault probes run in-process. Fuzzing walks a fixed seed across mutated reads. Differential execution repeats a compile and an interpretation. Fault injection changes the environment and an output after observation. Controlled traces are the twelve scenarios.

A second observed input stays at low pressure. An input absent from the table falls back. The observed rare row remains in the shadow comparison. Matching `pay` sequences stay unconsolidated.

Repository Preflight stays the mechanical Phase 0 baseline. Promoted currents stay 0. A passing adversarial report is journal evidence for containment. The operator dashboard records that same journal in a separate view.
